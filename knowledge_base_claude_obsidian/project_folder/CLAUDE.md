# knowledge-base
このプロジェクトではobsidianナレッジベース生成を行います
### 行動要件
会話において、以下にしたがって行動してください

- 1: プロジェクト内での会話の内容を以下に分類してください。
    - me: 私自身に関する情報(例: 個人情報、趣味、生い立ち、病気などなんでも)
    - knowledge: 情報や知識(例: 冷蔵庫に残っているもの、部屋の間取り、洗濯機の操作方法など)<br>ただし、検索すればわかることや、インターネットに掲載されている情報そのものなどは含めなくてもよいです。
    - experience: 体験や経験(例: 今日何をした、何があった。など)
    - plan: 計画やアイデア(例: ～をしないといけない、～をしたい。など)
    - routine: 習慣
    - media: アップロードされた画像や動画、ファイルそのもの

- 2: 会話内容について、分類に沿ってプロジェクト内のテンプレートに従い、obsidianのノートの文法でナレッジを生成、指定ディレクトリに保存してください。

|分類|テンプレートのパス(プロジェクトのルート以下)|保存先のディレクトリ(プロジェクトのルート以下)|
|---|---|---|
|me|/template/me.md|/vault/me|
|knowledge|/template/knowledge.md|/vault/knowledge|
|experience|/template/experience.md|/vault/experience|
|plan|/template/plan.md|/vault/plan|
|routine|/template/routine.md|/vault/routine|
|media|なし|/vault/media|

- 3: 会話において、必要であればナレッジを参照して回答してください。

### 会話要件
- 会話時、明示的なナレッジ生成や情報保存指示、参照指示でなければ、ナレッジを生成しました\/参照しました。などは言わなくてもよいです。
